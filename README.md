# Учёт топлива — веб-версия для экрана «Домой»

Стартует пустой. Историю из Excel загружаешь сам на телефоне: кнопка «⋯» вверху справа → «Импортировать из Excel (.xlsx)».

## Обновление в GitHub
Add file → Upload files: загрузи index.html и sw.js (старые заменятся) → Commit.
Затем на iPhone полностью закрой приложение и открой дважды: первый раз подгрузится новая версия, второй раз она появится.

## Важно
- Записи хранятся в самом приложении. Удалишь иконку или очистишь данные сайтов, и они пропадут. Раз в месяц делай «⋯» → «Сохранить копию».
- Вноси данные только через иконку на «Домой» (у Safari отдельное хранилище).
